重點整理

總口訣：「概念、提示、優化、倫理」四大考綱 —— 先懂 AI 是什麼，再學怎麼問，接著學怎麼問得更好，最後學怎麼安全負責地用。

考綱一：生成式 AI 方法與方法論

  • 生成式 AI 會使用神經網路，能建立文字、圖像、語音等新內容；「只提供搜尋結果清單」是搜尋引擎的特性。
  • 生成回覆時，利用預測對每個詞做概率性選擇；模型可以重新訓練以更符合目的。
  • 搜尋引擎能說明資訊來源；生成式 AI 能產生網路上找不到的新材料。
  • 估算未來數值（如 2200 年地球均溫）→ 預測性 AI。

LLM 訓練流程：

  1. 收集資料集
  2. 預處理與清理
  3. 準備輸入資料
  4. 微調超參數
  • 不同口音演繹電影對話 → 文字生成語音；動物尋家海報 → 輸出圖像 + 文字。
  • 客製化 Copilot / GPT：輸入一組指令和資訊，讓它準備好執行特定任務。
  • 結合兩位作家風格：用包含兩者作品的 Transformer 模型建立輕量 GPT。
  • 多科目輔導：客製 Transformer 模型 + 每科具體指令。
  • 多代理人分工（貸款流程）→ LangChain；商標、計畫書等現成商業方案 → ChatGPT。

考綱二：基礎提示工程

提示詞四大結構範例句型
角色 Role「你是一位在[目標受眾領域]有豐富經驗的高級行銷經理」
特定指令 Instruction「根據客戶對新產品的喜好程度，為他們生成郵件。請使用這些詳細資訊…」
上下文 Context「我們需要為清單[試算表連結]中的每個人生成電子郵件…」
約束與舉例 Constraints「郵件需個性化，語氣模仿一個有好消息要告訴你的摯友」
  • 提示詞鏈接：拆成子任務，上一個輸出 = 下一個輸入。
  • 思維鏈 CoT：給出推導步驟 + 解答範例（紅 + 藍 → 紫），引導逐步推理。
  • 反向提示詞：先讓 AI 問你需要的資訊，再生成內容（「讓我提供簡歷所需的每個關鍵細節，然後生成簡歷」）。

擴散模型生成圖像順序：

  1. 分詞 Tokenization
  2. 雜訊生成
  3. 擴散 Diffusion
  4. 優化演算法
  • 好的行程提示詞：具體天數、交通方式（飛到鄰近機場 + 租車）、地區景點。
  • 「總結」類提示詞：《魔戒》情節 500 字概括、今天會議主要議題（附會議記錄）。
  • 轉換簡報促進學習：「將內容轉換為吸引人且易於理解的格式」。
記憶技巧：四大結構「角指上約」→ 諧音「腳趾上藥」。擴散順序「分、噪、擴、優」→ 洗照片：先看懂要拍什麼(分詞)→ 撒滿雜點(雜訊)→ 慢慢顯影(擴散)→ 最後修圖(優化)。

考綱三：提示優化與資料驗證

  • 有偏見的提示詞會預設立場，例如「重點關注最重大影響」「強調可再生能源比化石燃料更好」。
  • 無偏見：引用獨立第三方研究，關注可行性見解與潛在策略。
  • 內容不符合個人狀況（健身計畫）→ 提供自己的時間表並說明身體限制。
  • 想要更詳細、更有針對性 → 要求詳細範例 + 指定領域（汽車與金融）。
  • 故事中保留圖表原意：「麵包師發現規律」故事中包含圖表資料，暗示高脂肪食物與藥物用量的關係。
  • 轉為正規報告：週淨利 → 季度報告（總淨利 + 平均淨利）；轉成宣傳單 / 語音 不適合。
記憶技巧：看到「強調、最重大、更好」等帶立場字眼 = 有偏見；看到「獨立、可行性、潛在」= 中立。優化提示詞三寶：「給背景、給限制、給範例」。

考綱四：倫理、法律、社會影響與安全

  • 正面影響：海量資料醫學研究、高效耕作、瞭解世界文化。
  • 未保護個資的後果：身分盜用、隱私訴訟、客戶失去信任。
  • 客服機器人風險：敏感資料處理不當、缺乏人為監督而不準確、歧視性輸入導致偏見（三者皆正確）。
  • 偏見資料訓練出偏見圖像 正確；ChatGPT 能可靠消除偏見 錯誤；應人工審查 正確。
偏見階段自駕車案例
資料收集攝像頭只在白天錄影
數據標注只標註停車標誌與紅綠燈
模型訓練行人依身高給不同加權值
部署銷往各處但只在單一城市測試
  • 查證：搜尋學術資源 是、權威資料庫 / 機構報告 是、用另一個 AI 查證 否（可能有同樣幻覺）。
  • AI 招募須考慮：個資法、勞動法、智慧財產權法。
  • 專利：AI 不能是唯一發明者，需實質人類貢獻（使用 AI 更正現有設計中不準確處）。
  • 提示詞避免 PII：姓名、年齡、位置、社群帳號。
  • 使用者須對生成內容負法律責任，有害或侵權內容可能引發民事或刑事訴訟。
記憶技巧：偏見四階段「收、標、訓、部」= 自駕車人生：先拍照(收)、貼標籤(標)、去上課(訓)、出門上路(部)。查證口訣：「AI 不能幫 AI 作證」。專利口訣：「AI 是工具，人才是發明人」。

記憶技巧：主格放動詞前（誰做），受格放動詞或介系詞後（做給誰）。所有格形容詞後面一定接名詞（my model），所有格代名詞單獨使用（The model is mine）。
be 動詞口訣：「I 用 am，you 用 are，is 跟著他她它，複數通通都用 are」。

用法對照

  • She trains the model. — 主格（她訓練模型）
  • The teacher helps her. — 受格（老師幫助她）
  • This is her prompt. — 所有格形容詞 + 名詞
  • The best prompt is hers. — 所有格代名詞（＝ her prompt）
  • She checked the answer herself. — 反身代名詞（她自己檢查）
  • The AI tool updates its data. — its（它的）≠ it's（it is）

第三人稱單數現在式：動詞加 -s / -es

規則原形 → 第三人稱單數
一般動詞 + sgenerate → generates、predict → predicts、train → trains
字尾 s, x, ch, sh, o + esfix → fixes、watch → watches、finish → finishes、go → goes
子音 + y → 去 y 加 iesstudy → studies、verify → verifies、apply → applies
母音 + y → 直接 + splay → plays、deploy → deploys
特殊have → has、be → is
記憶技巧：「他她它，動詞要加 s」。主詞是 he / she / it / 單數名詞（The model、ChatGPT）且是現在式，動詞就要變。否定與疑問改由 does 扛 s，動詞回原形：She doesn't use… / Does it work?

易混淆比較

比較差別
QA vs QCQA 品質保證：管「流程」，事前預防；QC 品質管制：管「產品」，事後檢驗。
IT vs MISIT 偏硬體、網路與技術支援；MIS 偏企業管理資訊系統（如 ERP）。台灣很多公司兩者通用。
FIN vs ACCTFIN 財務：管「錢的未來」（資金、預算、投資）；ACCT 會計：記「錢的過去」（帳務、報表、稅務）。
PR vs IRPR 公關：面對大眾與媒體（Public）；IR 投資人關係：面對股東與投資人（Investor）。
Admin vs GAAdmin 行政：公司整體行政管理；GA 總務：辦公用品、設施、庶務。小公司常合併為「行政總務部」。
PUR vs SCMPUR 採購：負責「買」；SCM 供應鏈管理：從採購、生產到出貨的「整條鏈」。
CS 一字多義部門名稱多指 Customer Service（客服部）；CSR 可能是 Customer Service Representative（客服人員）或 Corporate Social Responsibility（企業社會責任），要看上下文。

記憶技巧

  • HR = Human（人）+ Resources（資源）→ 人力資源，找工作、領薪水、請假都找 HR。
  • R&D：Research（研究）& Development（開發）→ 研發，「&」讀作 and。
  • Q 開頭都跟品質有關：QA 保證（Assurance，事前）、QC 管制（Control，事後）→「A 在前、C 在後」。
  • 看字首猜部門：MKT ← MarKeTing、ACCT ← Accounting、PUR ← Purchasing、LOG ← Logistics、WH ← Warehouse。
  • 「遇到問題找誰」口訣：電腦壞了找 IT、客戶抱怨找 CS、合約審閱找 Legal、買東西找 PUR、上媒體找 PR、新產品找 R&D。
